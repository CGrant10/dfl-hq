## §1 — the `AS` prefix

`AS` is generated by **`upLabel()` — `js/golf-match.js:74`**:

```js
const upLabel = (v) => (v === 0 ? "AS" : `${Math.abs(v)}${v > 0 ? "UP" : "DN"}`);
```

**Legitimate uses — leave alone:** line 348 (hole-by-hole `<td>` cells) and
line 478 (live cell updates). `AS` in a hole cell is correct match-play.

Two more producers: `js/golf-match.js:306` (`if (!up) return "AS"`) and
`js/golf-share.js:493` (`if (!lead) return "AS"`).

**Prime suspect for `AS Brando` — `standingLine(r, nameA, nameB)` at
`js/golf-battle.js:187`.** It takes the result *and both names*, and its output
is used as `where:` in the poster payload (`golf-match.js:285`). **Read it
first.** If it composes state + name, fix it there — return the state and the
name separately and let the renderer place them.

Clean contestant identity is rendered at `golf-match.js:556`
(`${names[0]} vs ${names[1]}`) — that one is already correct.

## §4/§5 — Teams section

**`js/pages/golf.js:157`** — one very long line. The whole team card is an
`<a>` ending in:

```html
<span class="gteam-open">View scorecard <b>→</b></span>
```

and the section subtitle reads *"Select a team to open its scorecard."*

That's the scorecard-menu behaviour to remove. Make the card a non-navigating
roster block: team name, colour accent, captain (already has an `#i-medal`
badge), player list. Keep `.gteam-*` classes where possible.

Scoring entry must survive elsewhere — see §13. `golf-scorecard.js` is the
entry point; find where else it is reachable before removing this link.
