# DFL interface copy

The owner wants titles, controls and real league data without explanatory or informational subtext. Do not add helper paragraphs, instructional captions, feature blurbs or methodology explanations unless explicitly requested.

Keep player/team names, scores, projections, counts, dates, availability, meaningful warnings, errors, loading states and accessible field labels. Authored league stories, Wall content and banter are content, not interface help. Anniversary branding is explicitly requested.

Disclosures render their title and body without a descriptive caption. Existing page/helper classes are suppressed by the shared mobile stylesheet; new work should omit helper copy at its renderer instead of introducing new caption classes.
