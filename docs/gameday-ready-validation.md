# GameDay readiness — v1.365.0

Home/GameDay and Clubhouse now refresh current scores when the document becomes visible, connectivity returns, or the page is restored from the browser's back/forward cache. Clubhouse also catches up when Matchups opens. These reads bypass the weekly-score and NFL-status caches. The shared scheduler coalesces wake signals, permits one in-flight refresh with at most one queued forced catch-up, and resumes the existing minute polling while the live view is visible. Hidden/offline views pause polling; completed Clubhouse weeks retain manual refresh. Route teardown removes timers and reconnect listeners.

A compact score-check label is visible beside Home's matchup and uses the same wording in Watch and Clubhouse. It distinguishes checking, successful checks, delayed data, failed reads, and offline scores without claiming a continuous push feed. Failed refreshes retain recorded totals. Missing NFL or player availability reads remain explicit; prior player metadata is retained when possible. Repeated label paints do not replace unchanged text or replay score effects.

Lineup check is a collapsed disclosure, shown only when submitted starters contain empty slots or upcoming/unknown players carry Questionable, Out, reserve, suspended, or doubtful designations. Home shows the selected member's starters; Watch and Clubhouse show both participants. Bench players, finished players, and completed weeks do not produce actionable warnings. Known kickoff times appear in warnings and upcoming player rows, using the viewer's local timezone. Missing schedule data stays pending. Warning updates preserve expanded details and focused player controls, including when all warnings disappear.

Live views use a five-minute player-directory cache lifetime instead of the ordinary daily lifetime. Identical in-flight directory reads are shared; metadata and weekly matchup fetches have twelve-second network timeouts. The existing Sleeper availability flags remain the source; this does not introduce an official inactive-list feed. Other directory consumers retain the daily default. No league data, scoring rules, player values, notifications, or messaging workflows change.
