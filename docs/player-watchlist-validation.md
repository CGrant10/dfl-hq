# Personal player watchlist · v1.374.0

Player cards now offer Watch player. Team Analyzer includes a personal radar with search, current ownership, weekly projections, verified kickoff state and targeted pickup/drop fit. Search uses current NFL teams to keep retired free agents from crowding the results. Saving clears search and keeps keyboard focus. Removing or refreshing keeps focus; refresh failures retain the last visible rows.

Lists hold up to 20 players per selected member on this device. The app has a member picker, not authenticated member accounts. An independent 256-bit browser capability protects each list; notification device tokens are never reused. Only a hash is stored remotely. Public tables have RLS, explicit deny policies, and no browser read/write grants. A public security-invoker wrapper calls a private, capability-checked function with a fixed search path. Member header alone cannot read another list. Clearing browser storage loses that device's list; this release does not claim account-wide cross-device synchronization.

Roster fit uses the existing legal nine-slot 1-QB PPR waiver model, current submitted starters, reserve/taxi ownership and protected bench values. Targeted candidates bypass the generic top-90/four-offer shortlist without changing ordinary waiver behavior. The panel always evaluates the selected member's roster, even while another team is selected for the season report. Missing roster mapping, schedule, projections or drop values withholds recommendations. Names come from current Sleeper users.

The private scheduled worker polls every ten minutes during the existing football-season/Chicago daytime window, with a two-minute lease and the existing auto-sync switch. First observations, new weeks, re-added players, stale observations and missing players establish baselines without announcing old news. Ownership changes only alert when an owned player becomes unowned across all twelve current rosters, including IR/taxi. Known injury changes and recovery alerts require a verified future kickoff. Own starter injury changes defer to enabled Matchups alerts. Unknown injury metadata never becomes a fake healthy status.

Watchlist alerts use the existing Waivers category. The worker and sender both check enabled device preferences; the sender also rechecks saved players before inserting an inbox message or pushing. Groups carry per-player revision keys so retries cannot repeat an already-sent event when a different event changes the group. Messages expire after two hours and open the Analyzer watchlist. Removing a player stops future events. No notification preferences are migrated or widened.

Validation covers legal lineup fit, protected drops, IR/taxi and ambiguous ownership, baselines, status changes, stale/week/re-add suppression, per-member device keys, member changes while requests are pending, grouped event retry dedupe and category exclusions. Live database rollback checks cover key/member isolation, idempotent saves, the capacity limit and removal. An anonymous REST read confirms the wrapper works while direct tables and missing-member requests are rejected. Validation fixtures are rolled back or intercepted in the browser; no real watches or test pushes are created.
