# GameDay GPU score effects — v1.276.0

Replaced the three CSS flame/icicle shapes with a JavaScript WebGL renderer. Fragment shaders generate turbulent flame crowns, rising embers, crystalline frost edges, cold mist, and drifting ice particles around the actual score glyphs. Each card/dialog shares one GPU surface across its visible scores. Number text, accessible temperature markers, and player/team eligibility remain unchanged: player fire above 15 immediately; player frost below 10 from Q3/final; team fire above 120 immediately; team frost below 100 after the existing starter halftime checkpoint.

Score masks and emitter fields upload only when content, fonts, layout, or theme change. Drawing uses small viewport/scissor regions, caps at 30 frames per second and 1.5 device pixels, and stops offscreen, in hidden tabs, in closed dialogs, with Motion off, and with reduced motion. Route teardown releases textures, buffers, programs, observers, listeners, and contexts. Lost GPU contexts recover; unavailable WebGL leaves readable static score cues. The modules join the service-worker app shell. Score labels sit below team/spotlight totals to leave room for the effects.

Validation: all 1,013 tests across 112 files, typecheck, identifier checks, and build passed. Chromium read-only matchup fixtures verified Q1/halftime fire, Q3-only frost, team boundaries, refreshed player totals, spotlight updates, motion preferences, accessibility, and 320px enlarged-text bounds. A standalone GPU fixture read changing framebuffer pixels and exercised motion suspension, offscreen suspension, emitter replacement, dialog close, context loss/restoration, unavailable WebGL, dark/light palettes, and teardown. Browser tests blocked production writes. These checks validate browser behavior; they do not benchmark physical mobile devices.
