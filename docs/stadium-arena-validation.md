# DFL Stadium Arena — 1.403.0

The primary Arena is a portrait-capable shared race room. Commissioners choose 2–32 active DFL members and 15–600 seconds, start a shared countdown, pause/resume, or edit while paused. Duration edits preserve normalized progress and the same draw; changing racers requires resetting the paused draw. Finished orders stay archived, and Race again creates another event. Existing active/completed legacy races keep their original renderer and results.

The server generates a cryptographic random draw. An independent seeded story gives the field continuous speed changes and lead changes, without weighting members or changing the official order. Every viewer derives positions from that manifest and the shared server clock, including late arrivals and replay. The last crossing is exactly at the configured duration. Replays are local and do not alter a result. The public manifest is reproducible, not cryptographically hidden; the interface reveals ranks as racers actually cross.

Commands require the existing verified Broadcast commissioner permission, lock the event row, and compare revisions. Public snapshots can finalize only a running race whose server clock reached its finish. Results and completion commit together and finalize idempotently. Stadium table guards prevent direct changes, engine downgrades, and moving a protected participant/result to a legacy parent. Private implementations are not exposed to anonymous or authenticated clients.

The 2D Canvas presentation uses stadium artwork, animated football runners, member identity badges, pack tracking, a focused battle camera, final sprint, and a finite finish celebration. Live positions reorder smoothly and preserve screen-reader order. App chrome and surrounding text follow the selected theme. Motion defaults on but respects both app Motion off and reduced motion. Portrait does not trigger the legacy rotation gate. Expanding the stadium is optional. Presence shows an anonymous browser count and never sends member identity. Hidden tabs suspend rendering/polling; offscreen stadiums skip Canvas draws. No position writes are streamed. Artwork loads only when Arena is opened.

Validation: deterministic paths for fields of 2, 12, and 32; monotone progress, exact final crossing, draw validation, leader changes, continuous velocity, duration edits, server countdown pause/resume, late joins, and track-camera bounds. `supabase/tests/stadium_arena.sql` exercises server commands, optimistic concurrency, anonymous denial, parent guards, archived-result protection, and idempotent finishing in a rollback-only transaction.
