# Home injury report — v1.279.0

Added an injury report broadcast slide with the four highest-priority affected players and a native full-report dialog. The current ESPN NFL injury feed covers all listed injured players; healthy/active news entries are excluded. DFL starters rank first, followed by DFL bench players, other NFL skill players, and other positions. Within each group, the existing fantasy ADP and player model supply importance. Ownership requires an unambiguous name, NFL team, and position match; duplicate reports use the newest athlete entry, including cleared statuses.

Rows show photos, position, NFL team, DFL owner and starter/bench role when known, injury body area, injury tag, and availability. Out means ruled out; IR and suspension mean unavailable; doubtful means unlikely to play; questionable means decision pending. Estimated return dates are not treated as confirmed participation. The full report supports player/team search and All NFL, DFL roster, and DFL starter filters. It shows source/check time and can be refreshed manually. A failed refresh preserves the last report and identifies the failure; an unavailable initial feed is distinct from an empty report.

The feed is cached for five minutes, reduced to essential fields, and checked every five minutes while Home is visible, or when returning to Home after a hidden interval. Route teardown removes the dialog, listener, and polling interval. Opening the report temporarily suspends broadcast rotation without changing the viewer's pause preference; closing it restores focus.

Validation: 1,020 tests across 113 files, typecheck, identifier checks, and build passed. Model tests cover availability uncertainty, fantasy priority, duplicate/cleared reports, ESPN identity shape, ambiguous ownership, and slide limits. Read-only Chromium checks used the actual feed (194 injured NFL players, six DFL starters and 17 bench players at validation time), exercised search and scope filters, successful/failed refreshes, native Escape/focus restoration, broadcast suspension, route cleanup, dark/light accessibility, 320px layouts, and 200% text. Production writes were blocked during browser checks.
